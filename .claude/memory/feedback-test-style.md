**规则:给 sando-rgbd 写测试,要"压力测试 + 真实环境 + 严格判据",不要抽查式简单用例。**

**Why:** 2026-05-25 用户多次强调:"简单测试没有太多意义"、"每一个 sector 做到最好"、"不用忠实复制 C++,告诉我功能/测了什么"。实证:抽查全绿后,改成随机批量 + 真实地图 + 对最优,又揪出 **6 个真 bug**(抽查全漏)。

**How to apply(用户要的测试种类,照这套来):**
- **随机批量压力测试**:几百张随机图/场景,而不是手挑 1–2 个例子;失败要能定位。
- **固定 seed 可复现**:随机测试用固定 seed,失败能复现。
- **对 ground truth / 暴力解**:能比最优就比(如 A* vs Dijkstra),不只看"跑通"。
- **真实环境**:用真实管道产物(如 read_map 输出,含 UNKNOWN/膨胀/热度叠加),不只手搓玩具地图。
- **真 3D**:起点终点/障碍/缝都在 x/y/z 用上,别拍平成 2D。
- **回归测试**:每修一个 bug,钉一个独立用例防复发。
- **安全不变量**:验"永远成立"的性质(路径不穿障碍内部、不越界、到终点),在随机图上批量验。
- **极端边界**:贴墙、负坐标、微地图、无解、起点=终点/在障碍内、边界坐标、越界输入 → 不崩 + 行为合理。
- **代价函数单调性 sanity**:改权重路径按预期变(权重↑→更躲),不是随机。
- **性能**:大图/密障碍/多动态,抓挂死和爆炸(阈值宽松、机器相关,只为防 blow-up)。
- **坐标/单位一致**:world↔voxel↔path 全程一致,尤其 origin/分辨率/floor 约定/负坐标。
- **判据要对**:碰撞 = 穿格子内部(有长度);擦角点/贴面(零长度)不算;别被采样假阳性骗。
- **诚实标注没测/测不了的**:边角极端情形、需要后续模块才能测的(如动态时间维度需 [[sando-rgbd-plan]] 阶段3 的 local_opt)。
- **标准是"对/最好",不是"和上游一样"**:新算法,不追求复刻 C++。
